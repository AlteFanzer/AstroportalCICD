# Astroportal — Астропортал

[![Deploy static content to Pages](https://github.com/AlteFanzer/AstroportalCICD/actions/workflows/deploy.yml/badge.svg?branch=main)](https://github.com/AlteFanzer/AstroportalCICD/actions/workflows/deploy.yml)

Учебный статический веб-сайт, посвящённый астрономии, планетам и исследованию космоса.

## Используемые технологии

- HTML — структура веб-страницы.
- CSS — оформление сайта.
- JavaScript — интерактивное мобильное меню.
- GitHub Pages — размещение сайта.
- GitHub Actions — автоматическая публикация проекта.

## Автоматизация CI/CD

Перед публикацией сайта выполняются автоматические проверки:

- HTMLHint — проверка HTML-разметки.
- Stylelint — проверка CSS-стилей.

После успешного завершения проверок сайт автоматически публикуется на GitHub Pages.
